# デモ進行メモ

## 事前準備
- [ ] リポジトリを GitHub に push 済み
- [ ] Jira に RB-1〜RB-6 を登録済み（`docs/tickets.md`）
- [ ] Orca でこのリポジトリを開き、Claude Code / Codex が起動できることを確認
- [ ] `npm run dev` が動き、ブラウザで表示できることを確認
- [ ] Orca の Jira/Linear/GitHub 連携の設定が済んでいる（事前に必ず実機で確認）

## 進行

| 場面 | 操作 | 見せたいこと |
| --- | --- | --- |
| 1 並行 | RB-1, RB-2, RB-3 をそれぞれ別 worktree のエージェントに投げる | 3つ同時に動く／誰が完了・誰が待ちかが一目でわかる |
| 2 比稿 | RB-4 を同じプロンプトで複数エージェントに fan-out | 実装方針が分かれる／良い方を選んでマージ |
| 3 diff コメント | 場面1か2の diff を開いて行コメント → エージェントに返す | 人は指摘だけ、直すのはエージェント |
| 4 チケット直達 | Jira 連携から RB-5 を開き、そのまま worktree を作って開発 | 書かれた仕様がそのまま実装される |
| 5 UI 直接指定 | Design Mode でヘッダーをクリックして指示 | 開発者でなくても指示が出せる |

## 失敗したときの逃げ道
- Jira 連携が動かない場合: チケット本文を手でプロンプトに貼る（結果は同じ）
- エージェントが止まった場合: 別 worktree の完了済み結果に切り替えて説明を続ける
